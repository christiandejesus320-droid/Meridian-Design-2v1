# Auditoría visual: OpenAI y Claude Design

## Claude Design

La página de Anthropic usa un fondo claro cálido, navegación compacta con logo, Research, Policy, Commitments, Learn, News y CTA Try Claude. El artículo coloca una etiqueta de producto, un titular central de gran escala, fecha y una pieza hero amplia con esquinas suaves. La tipografía es sans serif pesada para titulares y serif para el cuerpo editorial, creando contraste entre producto y artículo.

El contenido presenta el producto como una experiencia de colaboración: describir una necesidad, obtener una primera versión, refinar mediante conversación, comentarios inline, edición directa y controles. Los casos de uso cubren prototipos interactivos, wireframes, exploración visual, presentaciones, marketing y diseño de frontera con voz, vídeo, shaders, 3D e IA.

El flujo de producto se divide en pasos: sistema de marca incorporado desde código y archivos de diseño; importar prompts, imágenes, documentos y captura web; controles finos para texto, color, espaciado y layout; colaboración con permisos; exportación a Canva, PDF, PPTX o HTML; y handoff a Claude Code. La experiencia mezcla explicación editorial, video/product demo, integración de partners y CTA al producto.

## Aplicación a Meridian

Meridian debe usar una arquitectura de producto similar pero con identidad propia: fondo marfil y negro profundo, verde mineral y acentos coral/eléctricos para estados, tipografía display sans de alto contraste y una serif opcional para investigación. El hero debe mostrar una escena 3D o imagen 3D grande, no una tarjeta plana. Las landings de tecnología deben tener un sistema repetible: hero, para qué sirve, flujo de uso, integración, demo visual, CTA y fuente oficial.

## OpenAI

La referencia OpenAI usa navegación por ecosistema, hero conversacional, accesos a Investigación, Plataforma API y Business, y una arquitectura editorial de noticias, investigaciones, historias y productos. Sus tarjetas visuales usan imágenes grandes, composiciones científicas, fotografías documentales, textos cortos, fechas/categorías y enlaces de lectura. La home funciona como una puerta a producto, investigación y compañía.

## Sistema visual 3D propuesto

Para Meridian: Deep Ink `#111513`, Paper `#F1F0E9`, Mineral `#A9D6C8`, Forest `#315B4D`, Coral `#E67C5A`, Electric Blue `#6CC7FF` y Acid `#D8ED59`. El 3D debe representar contexto, conexión y movimiento: nodos orbitando un núcleo, tarjetas flotantes, un mapa de conectores, objetos de vidrio mineral y wireframes de documentos. Las imágenes pueden mezclarse entre renders 3D, capturas de producto, fotografías documentales e ilustraciones abstractas.

## OpenAI — observación visual de la home

La navegación usa un fondo claro y una línea superior compacta con logo, Investigación, Productos, Negocios, Desarrolladores, Empresa y Fundación. A la derecha aparecen búsqueda, login y CTA de producto. El hero usa mucho espacio blanco, una pregunta centrada, un campo de chat grande y chips de acceso para Business, Chat, Investigación y API. Debajo aparecen tarjetas grandes de producto y bloques editoriales con imágenes científicas, noticias, historias, investigación reciente y casos de empresas.

La dirección visual combina un sistema editorial sobrio con tarjetas de alto impacto: fotografías documentales, composiciones abstractas, imágenes científicas y videos de clientes. Los titulares son grandes, oscuros y directos; las categorías y fechas funcionan como metadatos. La home construye confianza mediante logos, historias de clientes, investigación, productos, API y un footer muy amplio que funciona como mapa de toda la plataforma.

Para Meridian se debe conservar la lógica —ecosistema, chat, módulos, archivo y CTA— pero reforzarla con 3D propio: un hero con núcleo orbital y conectores, tarjetas con profundidad y escenas de producto, un modo oscuro para tecnología y un sistema cromático mineral/coral/azul eléctrico.

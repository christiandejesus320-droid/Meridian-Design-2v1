# Meridian Skill Library

Biblioteca curada para diseño, contenido, MCP, producto y calidad web. La fuente oficial es [Vercel Skills](https://github.com/vercel-labs/skills).

No se instalarán mil skills de forma indiscriminada: Meridian mantiene una cola seleccionada y verificable para no aumentar dependencias ni introducir instrucciones innecesarias.

## Disponible

- `find-skills` — disponible desde `vercel-labs/skills`.

## Cola curada

- `frontend-design`, `web-design-guidelines`, `seo`, `content-strategy`, `brand-system`, `mcp-integration`, `ai-product-copy`, `case-study`, `performance` y `skill-creator`.

## Validación de landings

La home local muestra enlaces independientes para Home, Meridian, Plataforma, Fundador, Diseños, Publicaciones, Cosmos, Planes y Chat IA. La landing `mcp.html` carga con navegación común, hero grande, imagen, CTA hacia la fuente oficial, bloque “Cómo lo usamos”, sección de propósito y footer de tecnologías. El sistema nuevo usa una composición editorial normal y no inyecta el módulo de cuaderno en la home.

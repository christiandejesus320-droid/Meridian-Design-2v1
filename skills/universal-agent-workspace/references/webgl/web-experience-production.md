# Web Experience Production / Producción de Experiencia Web

## Purpose / Propósito

This guideline is used for production-grade experiences involving visual systems, performance-sensitive interfaces, and interaction-rich web product surfaces.

Esta guía se usa para experiencias de producción con sistemas visuales, interfaces sensibles al rendimiento y superficies web con interacciones ricas.

## Production principles / Principios de producción

- the app must remain usable without the visual layer
- performance is a product feature
- motion must be understandable
- accessibility is non-negotiable
- the system should remain maintainable

## Good delivery / Buena entrega

A web experience is production-ready when:

- the core product works without effects
- the effect is intentional and measurable
- fallbacks exist for low support
- motion is not distracting
- the system remains smooth and readable

## Operational checklist / Checklist operativo

- assess device constraints
- define fallback
- define motion policy
- test reduced motion
- validate in browser
- verify performance under real use

## Final rule / Regla final

Visual ambition should support clarity, not replace it.

La ambición visual debe apoyar la claridad, no reemplazarla.

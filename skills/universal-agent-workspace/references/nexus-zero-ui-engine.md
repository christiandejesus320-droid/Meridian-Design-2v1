# Nexus Zero UI Engine / Motor UI Nexus Zero

## Purpose / Propósito

This reference is used for premium, dense, dark UI systems that need to feel clear, technical, and operational without visual noise.

Este documento se usa para sistemas UI premium, densos y oscuros que deben sentirse claros, técnicos y operativos sin ruido visual.

## Visual principles / Principios visuales

- dark-first
- premium but quiet
- technical hierarchy
- high information density
- minimal ornament
- purposeful motion only

## Layout system / Sistema de layout

Use:

- 12-column grids where necessary
- subtle borders
- muted surfaces
- structured spacing scales
- consistent density

Avoid:

- excessive gradients
- noisy iconography
- decorative shadows
- superfluous cards

## UI contract / Contrato de UI

A useful dashboard surface should answer:

1. What is happening?
2. What is the current state?
3. What is the next action?
4. What is the risk or the status?

## Meridian direction / Dirección para Meridian

The app should feel like a control room for AI work, not a SaaS marketing page.

La app debe sentirse como una sala de control para trabajo de IA, no como una landing page de SaaS.

## Implementation guidance / Guía de implementación

- Use palette neutral/dark with a single accent color
- Prioritize readable type and clear hierarchy
- Keep controls compact but legible
- Use panels and split views intentionally
- Add motion only when it helps the user understand changes

## Acceptance check / Verificación de aceptación

A UI is successful when the user can understand:

- the system state
- the active task
- the current agent status
- the artifact or result being worked on

## Final rule / Regla final

Do not decorate the interface. Design the information so the user can act.

No decoréis la interfaz. Diseñad la información para que el usuario pueda actuar.

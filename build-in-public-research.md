# Build in public — investigación oficial

## OpenAI
OpenAI se describe oficialmente como una empresa de investigación y despliegue de IA con la misión de asegurar que la AGI beneficie a toda la humanidad. Fuente: https://openai.com/about/

## Anthropic
Anthropic se describe como una empresa de investigación y seguridad de IA que desarrolla sistemas fiables, interpretables y dirigibles. La página oficial lista como miembros del consejo a Dario Amodei y Daniela Amodei, entre otros. Fuente: https://www.anthropic.com/company

## Vercel
Vercel se presenta como infraestructura agentic para aplicaciones y agentes, donde humanos y agentes construyen software juntos. La página oficial no se usará para inventar un CEO; se mostrará su función como plataforma de deployment e infraestructura. Fuente: https://vercel.com/about

## GitHub
GitHub se presenta como una plataforma completa para construir, escalar y entregar software seguro. La página oficial ofrece brand assets y una sección de leadership; el logo se enlazará a sus assets oficiales. Fuente: https://github.com/about

## Google Workspace
Google Workspace se presenta como un conjunto de aplicaciones para trabajar desde un único lugar, colaborar en tiempo real, compartir archivos y proteger datos. Fuente: https://workspace.google.com/intl/es/products/

## Notion
Notion destaca su base de conocimiento, uso global, comunidad y adopción empresarial. Se mostrará como capa de conocimiento/documentación de Meridian. Fuente: https://www.notion.so/product

## MCP
MCP es un estándar abierto para conectar aplicaciones de IA con sistemas externos. La documentación oficial menciona acceso de agentes a Google Calendar y Notion, generación de apps desde Figma, conexión a bases de datos y creación de diseños 3D con Blender. Fuente: https://modelcontextprotocol.io/docs/2025-06-18/getting-started/intro

## Supabase

## Nota de implementación
Se usarán logotipos y brand assets desde fuentes oficiales cuando sea posible, y se crearán heroes originales de Meridian que representen la función de cada plataforma. No se copiarán sitios completos, texto protegido ni código de terceros. La ficha de CEO solo se incluirá cuando exista una fuente oficial actual verificable; si no, se mostrará equipo/empresa o función del producto.
